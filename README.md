# 엘리사마의 글방

https://guk7608.github.io/blog/

GitHub Pages(Jekyll)로 만든 개인 홈페이지입니다.

- 새 글: 사이트 맨 아래 **글쓰기** → GitHub에서 Commit, 또는 `_posts/YYYY-MM-DD-제목.md` 파일을 직접 추가
- 글 형식:

```
---
layout: post
title: "제목"
date: 2026-09-25 21:00:00 +0900
---

본문
```

- 홈페이지 이름·소개: `_config.yml`의 `title`, `description`
