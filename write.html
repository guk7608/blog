새 글
쓰던 글은 이 기기에 임시 저장됩니다

올리는 방법

  1. 제목과 내용을 적고 GitHub에서 올리기를 누릅니다.
  2. GitHub 화면이 열리면 글이 채워져 있습니다. 오른쪽 위 초록색 Commit changes…를 누르고, 한 번 더 Commit changes를 누릅니다.
  3. 1~2분 뒤 홈페이지에 새 글이 나타납니다.

GitHub에 로그인한 주인만 올릴 수 있습니다. 다른 사람이 이 페이지를 열어도 글을 올릴 수 없습니다.
글 수정·삭제는 GitHub 저장소의 _posts 폴더에서 해당 파일을 열어 연필(수정) 또는 휴지통(삭제) 아이콘을 누르면 됩니다.
